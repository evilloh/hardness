# Hardness

A mobile-first self-improvement and mental-wellness app, built with an **AI-native, spec-driven workflow**.

> **hardness** = *harness* (built with an AI harness) + *hard* (keeping your mind well is hard work).

The repository is built to show two things:

1. **The product**: four living lists (what drains, restores and lifts you, and what you long to do),
   a 1%-a-day practice tracker, a photo/notes journal, and evidence-based recommendations.
2. **The process**: how a senior frontend developer builds software with AI agents (specs, skills,
   subagents, hooks, verification loops) instead of ad-hoc prompting.

## Map

| Path | What it is |
|---|---|
| `CLAUDE.md` | Project memory the AI agent reads every session |
| `docs/product/` | Vision, users, scope |
| `docs/specs/` | One folder per feature: requirements → design → tasks |
| `docs/adr/` | Architecture Decision Records |
| `docs/research/` | Evidence policy and the medical/psychology sources we rely on |
| `docs/learning/` | AI-engineering notes: the concepts behind this workflow |
| `.claude/skills/` | Reusable agent skills (e.g. `/new-spec`) |

> ⚠️ This app is not a medical device and does not replace professional help.
