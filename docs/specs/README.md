# Specs

Every feature gets its own folder: `NNN-kebab-name/` (e.g. `001-wellbeing-toolkit/`).
Copy [`_template/`](_template/) to start one, or run the `/new-spec` skill.

## The three phases (each needs the user's approval before the next)

| File | Question it answers | Who it's for |
|---|---|---|
| `requirements.md` | **What** and **why**: user stories + acceptance criteria | Product (you, as PO of this project) |
| `design.md` | **How**: components, data model, state, edge cases | You + the agent, before coding |
| `tasks.md` | **In what order**: small, verifiable implementation steps | The agent, one task per loop |

## Status values

`Draft` → `Approved` → `In progress` → `Done`
